# 昊哥-产品起名就能卖

> 给技能、产品、商品、店铺、栏目起一个自带销售力的名字。
> 基于华杉《超级符号就是超级创意》方法论：命名=成本=召唤。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 为什么造它

昊哥，26年汽车行业老兵，现在做 AI 技能、做内容、做产品——**每个产品都要起名**，而起名最容易犯的错就是拍脑袋：起一个自己觉得有创意、客户听不懂的名字，传播成本极高。

这套方法来自华杉《超级符号就是超级创意》：**命名=成本=召唤，命名=投资**。本技能把书里的方法论固化成可重复执行的五步作业流程。

**自举验证**：本技能的名字（昊哥-产品起名就能卖）和另一个技能的改名（昊哥-读新闻拿观点），都是用这套五步法产出的——方法先用在方法论自己身上。

## 它解决什么问题

- 起名靠拍脑袋，没有章法可依
- 名字不带销售力：客户看到名字，不知道"跟我有什么关系"
- 名字拗口、要解释"哪个字怎么写"，转述一遍损耗一半
- 改名只改名字一个点，README、说明、口号没跟着动，体系散了

## 主要功能

- **五步作业法**：回到产品本身 → 找文化母体 → 卖点直接进名字 → 四道测试 → 定版即投资+体系联动
- **四道测试关**：电话测试法 / 传得动吗 / 绕开心理防线 / 谚语口语形式
- **固定候选格式**：每个名字附逐条检验+文化母体说明+推荐排序，**只推荐不代钦定**
- **著作权边界内置**：基于华杉方法论，只提炼流程不搬原文

## 使用方法

对 AI 说触发词：

- 「给我的 XX 起个名字」
- 「这个产品名要不要改」
- 「用华杉的方法给 XX 命名」

AI 会走五步作业法，产出带检验的候选名清单。

## 输入输出示例（真实案例：新闻洞察技能改名）

**输入**（产品三件事）：

> 目标人群：每天大量读行业新闻的内容创作者；解决的问题：新闻读完记不住、看不出观点；特性：一条链接进，一张认知卡片出。

**输出**（节选）：

| 候选 | 电话测试 | 传得动 | 防线 | 谚语形式 |
|---|---|---|---|---|
| 昊哥-读新闻拿观点 | ✓ 7字全常用 | ✓ "就是读新闻拿观点那个技能" | ✓ 无自夸 | ✓ 理由+指令结构 |
| 昊哥-新闻吃透 | ✓ | 一般 | ✓ | ✗ 缺结果承诺 |
| 昊哥-新闻代读 | ✓ | ✓ | ✓ | ✗ 只打省时，价值说小 |

**钦定结果**：「昊哥-读新闻拿观点」。随后 README、About、说明整套联动改——名字是体系的第一块砖。
