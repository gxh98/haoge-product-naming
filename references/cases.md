# 原文案例库（详版）

> 信源：华杉在樊登「作者光临」对谈《超级符号就是超级创意》录音转写（2025-09-07，39分钟）。案例归原作者所有，此处仅作方法论说明。

## 命名案例

| 案例 | 方法点 |
|---|---|
| 阿里巴巴 vs 腾讯 | 文化母体符号（有故事、好记好传） vs 要逐字解释的编码 |
| 西郊庄园 vs 南桥圣飞 | 命名=成本=召唤：低成本一秒唤起庄园场景，高成本要解释"草字头下面一个非常" |
| 海底捞百分百纯牛油锅底 | 卖点直接进名字，哪怕字长；比"产品名+广告语"更权威 |
| 可可冰喉30分钟长效润喉糖 | 卖点（30分钟长效）是注册商标，名字即承诺 |
| 别克贵宾级商务车 | 名字自带溢价感（"感觉都贵5万块钱"） |
| 田七长牙牙/换牙牙牙膏 | 三个字的名字比广告语厉害，还给妈妈一个选择逻辑（2-5岁长牙 / 6-12岁换牙） |
| 匡迪保温杯 | 命名=投资：取了名字就永远投资它 |

## 话语与符号案例

| 案例 | 方法点 |
|---|---|
| 困了累了喝红牛（vs 你的能量超乎你想象） | 听觉第一；凡人们不会使用的话都不要说；东鹏特饮改两字接走做到100亿 |
| 爱干净住汉庭（vs 更干净住汉庭） | 绕开心理防线；购买三件套=理由（爱干净）+指令（住汉庭）+指南（价目表） |
| 新东方老师好（vs 好老师在新东方） | 文化母体（从小喊的"老师好"）碾压自夸 |
| 厨房酱油"晒足180天"+餐桌布绿格子 | 母体预制件：绿格子让人有食欲，熟悉感免论证 |
| 云南咖啡好认准四只猫 / 一吃海底捞马上没烦恼 | 谚语形式：绕开防线、损耗最低、能传承 |
| 蜜雪冰城雪王+170年前老歌 | 成为母体、放大母体（雪人+王冠+冰淇淋权杖都是预制件） |
| 微信红包 | 文化母体四步法：寻找（过年红包）→回到→成为（电子红包）→放大（一年发千倍） |
| 洽洽每日坚果包装 | 三现主义调研（90%顾客问"里面有啥"）→包装放每种坚果图片→决策简单 |
